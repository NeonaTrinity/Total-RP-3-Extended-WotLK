
Alpha 16 focus:
- Campaign/quest breadcrumb payload compatibility and safer ID construction.
- Explicit deletion for user-created campaigns and nested database objects.
- Database list scrolling on the Wrath client.
- WotLK-safe icons for Create Item/Campaign and workflow element selectors.
- Campaign action macro icon fallbacks for Listen/Talk.
- Fixed historical Campaign 'Create From' clone call while preserving Item 'Create From'.
- Centered/clamped object browser so Create From can always be closed.
- Workflow selector close button/unlock behavior and missing Middle-click localization fallback.
- Custom campaign NPC Look fallback for name/description.
- Lighter quest/dialog presentation with dark readable text.
- Clean Extended item sharing: normal chat carries only [Item Name]; supported private/group channels send metadata separately over addon chat so Alpha 16 clients can render a clickable Extended link.

Notes:
- Loose dropped items remain local to the dropper by original 1.0.7 design. Shared stashes are the multiplayer ground-storage feature.
- Remote stashes require the owner to be online; allowing remote deposits is deferred as a future feature.
- Wearable items use an inspection marker/pose, not a 3D transmog model.
- Campaign reset/start-pause behavior remains faithful to 1.0.7. User-created campaign objects can now be explicitly deleted.


Alpha 15 focus:

- Extended icon browsers now open as anchored DIALOG frames instead of behind/in the stock TRP3 popup container.

Known fidelity limitation
-------------------------
The historical TRP-Anim-DB git submodule was absent from the 1.0.7 archive.
The WotLK port still uses compatibility fallbacks for model animation/scaling.
This does not prevent inventory, items, quests, documents, dialogues, or
creation tools from loading, but exact historical model scaling/animation is
not yet fully restored.

TRP3 Extended WotLK Alpha 12
============================

This build keeps the public totalRP3 / totalRP3_Data WotLK backport untouched.

Alpha 12 functional compatibility pass:
- Wrath casting-bar compatibility (Arcano-Casino and other cast effects)
- Wrath macro icon-index conversion for campaign LOOK/LISTEN/ACTION/TALK macros
- strict boolean per-character CreateMacro argument
- wearable placement drag fixes and clearer marker/animation-time labels
- RP trade OnHide cleanup so closing/cancelling releases suspended inventory slots
- /trpext, /trptext and /trpextended slash aliases; `search` scans nearby dropped items

Wearable note: Extended 1.0.7 does not attach a 3D item model/transmog appearance.
The wearable flag exposes an inspection-location marker; position/pose are configured
from the green locator button beside the item in the player RP inventory.
