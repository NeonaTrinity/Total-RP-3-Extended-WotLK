Known fidelity limitation
-------------------------
The historical TRP-Anim-DB git submodule was absent from the 1.0.7 archive.
The WotLK port still uses compatibility fallbacks for model animation/scaling.
This does not prevent inventory, items, quests, documents, dialogues, or
creation tools from loading, but exact historical model scaling/animation is
not yet fully restored.
