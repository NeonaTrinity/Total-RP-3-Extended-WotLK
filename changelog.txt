TRP3 Extended WotLK Alpha 20
================================

Workflow modal close-state fix:
- Add Element selector X now closes the entire element-editing modal and returns to the workflow.
- Effect/Condition/Delay editor X now performs the same full unwind.
- Nested Condition operand frames are cleaned up during the unwind.
- The workflow is explicitly unlocked and highlights cleared.
- A subtle dark modal backdrop is restored so element-editing mode is visually obvious, but its own redundant X remains hidden; the visible child X is the single exit control.
- Refresh/tab/hide paths clear stale element-editor state instead of leaving an invisible mouse-blocking frame.


TRP3 Extended WotLK Alpha 19
================================

Focused UI-state fixes:
- Quick-mode item editor now opens centered/clamped over Extended Tools instead
  of using API-11 hover positioning that could place it above/off-screen.
- My Database right-click menu has an explicit Edit action.
- Campaign custom-NPC ID information button copies the currently targeted NPC
  ID again and stays visible.
- Chat-linked item tooltip is dismissible by clicking the same link again or
  clicking the tooltip, and has a hard 30-second lifetime.
- Condition operand layer has its own visible close button and cleans up nested
  operand frames on every exit path.
- Dropdown submenu levels are clamped on show; right-edge submenus mirror left.


TRP3 Extended WotLK Alpha 18
================================

Focus: UI/editor usability restoration.

- Global Extended popup/browser placement chooses a safe side and clamps to screen.
- Reparented icon/color/image/object browsers are explicitly hidden by the Extended popup manager.
- Inventory icon browser prefers below the character model and remains screen-clamped.
- Clicked RP item chat tooltip is pinned at the mouse for 10 seconds.
- Offered RP trade items can be dragged out of the exchange (same effect as removing the offer).
- Campaign names are width-limited/ellipsized; quest title presentation widened and gold.
- Campaign NPC descriptions are also appended directly to the stock GameTooltip on Wrath.
- Campaign Action rows now have an explicit right-click Edit / Condition / Delete menu.
- Condition editor/operand overlays are clamped and given explicit close behavior.
- Battle-pet wording is replaced with Wrath non-combat companion/critter terminology.

Action naming note:
Original Extended internally calls the Inspect action LOOK. TRP3_Look intentionally calls
TRP3_API.quest.inspect(); this is the original 1.0.7 naming convention, not the wrong function.

Known remaining focus:
Campaign/workflow effects and conditions still require live testing one family at a time.
The original TRP-Anim-DB submodule data is still absent from the supplied 1.0.7 archive.


Alpha 17:
- Removes permanent campaign deletion from Quest Log. Destructive deletion stays in Tools/database management.
- Widens/spaces database tabs and truncates overflowing labels with ...; hover shows full text.
- Fixes condition operand Args/Edit/Preview child aliases lost by Wrath nested parentKey handling.
- Routes Extended Tools listboxes through an API-34 compatibility helper so menu width no longer becomes a huge horizontal popup offset.
- Guards later dialogue alpha-gradient and sound-history hyperlink widget methods.

Known reduced/deferred 1.0.7 areas found by the compatibility audit:
- TRP-Anim-DB is absent from the supplied archive; dialogue/cutscene model scaling, paired-model placement and exact animation timing still use fallbacks.
- Encounter Journal instance lookup has no Wrath equivalent and uses a neutral fallback.
- Mount/companion journal APIs are emulated over Wrath companions; editor behavior is less complete.
- The later companion-browser popup is not present on the WotLK base.
- UnitPosition is approximated from Wrath map coordinates for Extended location/distance logic.
- Workflow/effect/condition logic is present from 1.0.7; the largest remaining work is adapting API-34 frame layouts and later client APIs, then live-testing each effect/operand.

Install all three Alpha 17 Extended folders if you want full 1.0.7 import/export support. Do not edit totalRP3 or totalRP3_Data.

Alpha 13 restoration / compatibility pass
------------------------------------------
- Adapts Extended's later communication progress API to the API-11 WotLK
  transport so custom item definitions can be requested during RP trades.
- Restores the five historical Extended toolbar entries on a separate movable
  WotLK-safe action bar instead of using the broken stock TRP3 toolbar path:
    * RP Inventory
    * Ground Items / Stashes
    * Quest Log / Campaign Actions
    * Sound History
    * Extended Tools
- Adds an RP Trade action to the TRP3 target-action frame.
- Restores target inventory inspection without requiring the later
  character.extended capability flag that the WotLK backport does not send.
- Shows a custom item icon while dragging RP inventory items.
- Adds right-click deletion of owned root creations in the Add Item/object
  browser, with confirmation.
- Re-enables basic Extended Tools guided tutorials using Wrath GameTooltip and
  a simple highlight border.
- Keeps container opening on double-click; this is original 1.0.7 behavior.
- Keeps individual ground drops local to the dropper, matching the original
  local TRP3_Drop search design. Shared stashes use the multiplayer protocol.

Known fidelity limitation
-------------------------
The historical TRP-Anim-DB git submodule was absent from the 1.0.7 archive.
The WotLK port still uses compatibility fallbacks for model animation/scaling.
This does not prevent inventory, items, quests, documents, dialogues, or
creation tools from loading, but exact historical model scaling/animation is
not yet fully restored.

TRP3 Extended WotLK Alpha 12
============================

This build keeps the public totalRP3 / totalRP3_Data WotLK backport untouched.

Alpha 12 functional compatibility pass:
- Wrath casting-bar compatibility (Arcano-Casino and other cast effects)
- Wrath macro icon-index conversion for campaign LOOK/LISTEN/ACTION/TALK macros
- strict boolean per-character CreateMacro argument
- wearable placement drag fixes and clearer marker/animation-time labels
- RP trade OnHide cleanup so closing/cancelling releases suspended inventory slots
- /trpext, /trptext and /trpextended slash aliases; `search` scans nearby dropped items
- bundled Simple Rifle numeric sounds mapped to Wrath gun-load/gun-fire MPQ paths

Wearable note: Extended 1.0.7 does not attach a 3D item model/transmog appearance.
The wearable flag exposes an inspection-location marker; position/pose are configured
from the green locator button beside the item in the player RP inventory.
